# Walk-Forward Testing

> [!info] In one line
> Tuning on old data, then testing on data never seen.

The honesty check. Set the strategy up using the first chunk of history, then run it on a later chunk it has never touched.

If results collapse on the unseen data, the strategy was memorising the past rather than finding something real. This gate isn't optional.
